# What loads automatically

Always-on (every session): User Rules charter + 7 alwaysApply `.mdc`. On task match: one skill. On invoke: hunter/cut/prove. Hooks emit `continue` / `permission` / one advisory `followup_message`.

Keep always-on instructions short: they cost context every session. Skills and docs cost only when read. If context pressure becomes a demonstrated problem, measure a representative session instead of estimating bytes/4.
