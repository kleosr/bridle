# What loads automatically

Always-on (every session): User Rules charter + 7 alwaysApply `.mdc` bodies. Glob companions load when the host matches globs — still not proof they apply (companions self-check the owning package).

On task match: skill **discovery** (name + `description:` router) may enter context; skill **bodies** (`SKILL.md` + SOURCE) load when Read. On invoke: hunter/cut/prove. Hooks emit `continue` / `permission` / one advisory `followup_message`.

Intended model above is not a measured token budget. Discovery metadata, project `AGENTS.md`, and agent instructions can cost context even when skill bodies are unread. If context pressure is a demonstrated problem, measure a representative session in the supported client (do not estimate bytes/4).
