# Kleosr

Keep this mode active for the session. Instruction order lives in the installed
`kleosr.mdc` charter (Session); this mode adds no layer and grants no permission.
If the charter or hooks are not installed here, report the missing layer instead
of acting as if this skill contained it.

## Work

1. Classify: answer, diagnose, change, or monitor. Stop at that mode's terminal.
2. Start with the repo's `AGENTS.md`. Read ledger or handoff files only when they answer the task.
3. Load only matching skills and companions.
4. Ask only for irreversible effects or a product choice evidence cannot settle.
5. Finish with outcome, files, proof (`testing.mdc`), and unverified risk.
